# Colombo District Urban Heat Island (UHI) Analysis 🛰️🌡️

An interactive geospatial analysis project using **Google Earth Engine (GEE)** and **Landsat 8 Collection 2 Level 2** satellite imagery to study the relationship between Land Surface Temperature (LST) and vegetation cover (NDVI) across the Colombo District, Sri Lanka (2023).

## 📌 Key Features
- **Land Surface Temperature (LST) Mapping:** Extracted thermal infrared data (Band 10) to map surface heat distribution.
- **Vegetation Dynamics (NDVI):** Quantified green cover to evaluate urban vegetation health.
- **Interactive UI & Dynamic Legends:** Built responsive widgets and custom dynamic legends using the GEE User Interface API.
- **Statistical Correlation:** Generated scatter plots demonstrating the inverse relationship between NDVI and LST.

## 🛠️ Tech Stack & Data Sources
- **Platform:** Google Earth Engine (JavaScript API)
- **Dataset:** Landsat 8 Collection 2 Level 2 (`LANDSAT/LC08/C02/T1_L2`)
- **Boundary:** FAO GAUL Level 2 (`FAO/GAUL/2015/level2`)

## 🚀 How to Run the Script
1. Open the [Google Earth Engine Code Editor](https://code.earthengine.google.com/).
2. Copy the code from `colombo_uhi_analysis.js`.
3. Paste it into the editor and click **Run**.
